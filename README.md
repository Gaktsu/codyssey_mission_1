# 코디세이 미션 1 - 개발자 환경 세팅

## 1. 프로젝트 개요

### 1.1 프로젝트 목적

Linux CLI, Docker, Git/GitHub를 활용하여 개발 환경을 구축하고 각 기술의 기본 개념과 동작 원리를 이해하는 것을 목표로 한다.

단순히 개발 도구를 설치하고 실행하는 것에서 끝나는 것이 아니라, 직접 명령어를 실행하고 결과를 검증하여 재현 가능한 개발 환경을 구성한다.

또한 실습 과정에서 발생하는 문제의 원인을 분석하고 해결하는 트러블슈팅 과정을 기록한다.

### 1.2 주요 수행 내용

**Linux CLI**
- 기본 명령어를 활용한 파일 및 디렉토리 관리
- 파일 및 디렉토리 권한 확인과 변경

**Docker**
- Docker 설치 및 실행 환경 확인
- Docker 이미지와 컨테이너 관리
- Dockerfile을 활용한 커스텀 이미지 제작
- 포트 매핑을 통한 웹 서버 접속
- 바인드 마운트 및 볼륨을 활용한 데이터 관리

**Git/GitHub**
- Git 사용자 정보 및 기본 브랜치 설정
- VSCode와 GitHub 연동
- GitHub 원격 저장소를 활용한 소스코드 관리

**문서화**
- 주요 명령어 및 실행 결과 기록
- 각 기능의 동작 검증
- 트러블슈팅 2건 이상 기록

### 1.3 최종 결과물

본 미션에서 다음 결과물을 완성하는 것을 목표로 한다.

- Dockerfile 기반 커스텀 웹 서버 이미지 및 컨테이너
- 포트 매핑을 통한 웹 서버 접속 결과
- 바인드 마운트 및 볼륨 영속성 검증 결과
- Linux CLI 및 Docker 명령어 실행 기록

- 트러블슈팅 기록
- 전체 수행 과정이 정리된 README.md
